03

How I build

The same shape shows up in Gcina, BonaBlock and SafeGuard. It is not a slogan, it is where the bugs are not.

1

Software proposes. Something independent decides.

An agent drafts the payment, the work order or the report. A co-signer, a reviewer or an on-chain rule has the final say, and the system is built so the agent cannot route around it.

2

Verifiable without trusting us.

Digests on a public chain, a standalone verifier with its own RPC, sample data labelled as sample data. If the claim cannot be checked by a stranger, it is not a claim yet.

3

Built for the phone people actually have.

Low data, pay-as-you-go, WhatsApp first, isiZulu and isiXhosa where it matters. Fast on a cheap Android or it does not ship.
